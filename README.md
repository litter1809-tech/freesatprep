# APEX 1600 — Digital SAT Mastery Studio

**Live Site:** [https://litter1809-tech.github.io/freesatprep/](https://litter1809-tech.github.io/freesatprep/)

A free, self-contained Digital SAT preparation studio built to help students train for a 1500–1600 score—no account, backend, or build step required.

## Key Features

- **Adaptive Digital SAT Bluebook Mocks** — Full-screen Bluebook-style exam mode with adaptive module routing, timed sections, and realistic scoring.
- **Embedded Official Desmos Calculator** — Slide-over official Desmos Graphing & Scientific calculator powered by the Desmos JS API, ready to use right alongside any math question.
- **Per-Choice "Why Wrong?" Explanations** — Detailed answer breakdowns explaining not only why the correct answer works, but why each distractor is wrong.
- **Learn Every SAT Section Study Hub** — Structured guides, playbooks, formulas, and Desmos strategies covering every Reading & Writing and Math domain.
- **SM-2 Mistake Vault** — Spaced-repetition mistake tracker using the SM-2 algorithm to resurface missed questions right before you forget them.
- **Save & Pause / Portable Progress Codes** — Pause exams or practice anytime and transfer your full study progress across devices with portable save codes.
- **Friend Duels** — Challenge friends head-to-head on timed SAT question sets.

## Running Locally

Because the entire app lives in a single static [`index.html`](./index.html) file, you can open it directly in any modern browser or serve the repository root with any static HTTP server.
